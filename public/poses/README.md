# Pose reference thumbnails

Hovering a pose in the studio's "Add poses" panel shows the image named here.
A pose with no file simply shows no popover — drop them in a few at a time.

- **Category art** (wins): `public/poses/<category>/<slug>.jpg`
- **Shared fallback**: `public/poses/<slug>.jpg` — used by every category that
  has no file of its own, which suits the poses shared by menswear and
  womenswear.

Portrait crops look best; the popover renders them at 4:5, 184px wide.
The slug comes from the pose label (see `poseSlug` in
`src/lib/client/constants.ts`) — rename a label there and the file must follow.
